1. 완전탐색

   N개의 레일 배치는 N!

   모든 경우에 대해서 값을 구한다 N

   = O(N! * N)

   

   시간 복잡도만의 문제가 아니라!!

   O(N) 과정을 진행할 때, 실제로 최종 속력 값을 구할 수 없다. av + b 꼴로 진행하기 때문에, 숫자가 매우 커진다.

   

2. 정답 배치를 구하기

   정답 배치의 수열을 두고 이 수열의 성질을 생각해보자.

   ex) (a1, b1) -> ... -> (ai, bi) -> (ai+1, bi+1)

   ​	   (a1, b1) -> ... -> (ai+1, bi+1) -> (ai, bi) 

   최적의 배치가 있는데 그 안에서 순서를 바꾸면 최적 배치와 같거나 크다.
